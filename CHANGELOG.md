# Changelog

Все значимые изменения проекта Obsidian Vault Performance задокументированы в этом файле.
Версионирование следует [Semantic Versioning](https://semver.org/).

## [1.4.0] — 2026-10-01

### Added
- **vault-relevance-finder** — новый агент для поиска семантически связанных заметок внутри dirty-доменов при изменении одной заметки
- **build_topic_graph.py** — скрипт для построения графа тем и доменов с отслеживанием грязных доменов (dirty domains)
- Планы фаз разработки в `.claude/plans/`

### Changed
- Оптимизированы скрипты очистки временных файлов (`cleanup.py`)
- Улучшена логика кластеризации по темам (`cluster_from_topics.py`)
- Расширены возможности синтеза таксономии (`synthesize_taxonomy.py`)
- Обновлены правила репозитория в CLAUDE.md

### Improved
- Инкрементальный анализ vault работает эффективнее
- Пересчитываются только грязные домены (те, где были изменения)
- Ускорено нахождение связанных заметок для анализа влияния изменений
- Граф тем отслеживает зависимости между доменами и заметками

### Fixed
- Ошибки при обработке относительных путей (частичное решение из v1.2.0)

### Notes
- Добавлено правило 9: спека (speckit-* скиллы, `.specify/`, `specs/`) не коммитится в гит — это инструменты планирования, не часть релиза
- Нет breaking changes. Существующие taxonomies совместимы с новыми инструментами анализа

---

## [1.3.0] — 2026-09-27

### Added
- Правила делегирования тяжёлых фаз через `llm-ssh` в CLAUDE.md

### Changed
- Обновлена навигация и структура CLAUDE.md
- Расширены инструкции по фильтрации мусорных файлов
- Обновлена логика `semantic-taxonomy` SKILL.md для новых фаз обработки

### Improved
- Инструменты и правила проекта более понятны и структурированы
- Процесс анализа vault более формализован

### Notes
- Версия сосредоточена на документации и инструкциях для разработчиков
- Не содержит breaking changes

---

## [1.2.0] — 2026-09-18

### Added
- Расширенный фильтр мусорных файлов (шаблоны, пустые заметки, вложения)
- Двухступенчатая фильтрация перед семантической кластеризацией:
  - Эвристики без LLM (первый проход)
  - Сигналы `vault-topic-classifier` (второй проход)

### Changed
- Оркестрация построения семантической таксономии оптимизирована

### Improved
- Анализ доменов vault более надёжен
- Повышена стабильность работы с относительными путями
- Целевые файлы (шаблоны, вложения, пустые заметки) гарантированно не попадают в анализ доменов

### Fixed
- Ошибки при обработке относительных путей в конфигурации VAULT_PATH

### Notes
- Отсеянные файлы сохраняются в секции `filtered_out` итогового `taxonomy.json`
- Нет breaking changes
- Версия стабилизирует фильтрацию мусорного контента перед анализом

## Как использовать Changelog

- Найди свою версию в списке выше
- Для обновления на новую версию проверь секции `Changed`, `Improved`, `Fixed`
- Для миграции между версиями см. раздел `Notes` каждой версии
- Breaking changes явно указаны в заголовке версии
