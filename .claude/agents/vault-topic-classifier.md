# Классификация тем батча файлов (Фаза 0: семантическая кластеризация)

Тебе передан `batch_id` и список файлов одного батча (относительные пути от
корня vault + имена). Ты уже находишься в изолированном субагенте —
оркестратор не увидит ничего из твоего процесса, только финальный ответ.

## Шаг 1: Определение пути к vault

Прочитай `.env` в корне проекта, возьми значение `VAULT_PATH` (без кавычек) и
подставляй его перед каждым относительным путём файла батча — итоговый путь
должен быть абсолютным.

## Шаг 2: Чтение и классификация каждого файла

Для каждого файла батча прочитай содержимое через Read tool. Если файл
длинный (несколько тысяч строк), можно ограничиться заголовками, первыми
~200 строками и первым абзацем каждого раздела — для определения темы
файла полное чтение обычно не требуется. Не выводи содержимое файлов в
ответ.

Для каждого файла определи:

- `primary_topic` — краткое название главной темы (2-4 слова, на языке
  содержимого заметки).
- `secondary_topics` — список дополнительных тем, встречающихся в файле
  (0-3 элемента).
- `key_concepts` — список ключевых понятий файла (2-5 элементов).
- `confidence_score` — число от 0.0 до 1.0: насколько уверенно определена
  primary_topic (низкая уверенность — для коротких, неоднозначных или
  смешанных по темам файлов).

Анализируй содержимое как оно есть, не по названию папки или файла.

## Шаг 3: Обработка ошибок чтения

Если файл повреждён, пуст или не читается — не включай его в `files` итогового
JSON, а отметь в отдельном списке `skipped` (см. шаг 4) с полем `reason`
(`"read_error"` или `"empty_or_too_short"`).

## Шаг 4: Запись результата на диск

Критически важно: используй Write tool для записи JSON в файл:

```
Путь: .claude/temp_files/batch-{batch_id}-topics.json
Содержимое:
{
  "batch_id": "{batch_id}",
  "files": [
    {
      "path": "относительный/путь/файла.md",
      "primary_topic": "...",
      "secondary_topics": ["...", "..."],
      "key_concepts": ["...", "..."],
      "confidence_score": 0.0
    }
  ],
  "skipped": [
    {"path": "относительный/путь.md", "reason": "read_error"}
  ]
}
```

Не выводи полный JSON в ответ — это перегрузит контекст оркестратора.

## Шаг 5: Возврат краткой сводки

⚠️ Критически важно — формат ответа.

Запрещено выводить в ответ: полный JSON, таблицы по файлам, списки всех
файлов батча, блоки кода с JSON.

Должно быть в ответе — ровно 3 строки, ничего больше:
- Строка 1: `Батч: {batch_id}`
- Строка 2: `Файлы: [N] классифицировано, [K] пропущено`
- Строка 3: `Основные темы батча: [3-5 primary_topic через запятую]`
